# Skills

The skills in `skills/` (installed at `.opencode/skills/` when this repository
is cloned into Albada) are the current pinned inputs to the creator's workflow;
`skills-lock.json` records their sources and integrity hashes. OpenCode
auto-discovers `.opencode/skills`, so no `skills` key is needed in
`opencode.json`.

Skills are optional recommendations for Albada contributors. Third-party skill
content remains subject to its upstream license and attribution requirements.
Do not treat a skill as a replacement for Albada's `AGENTS.md`, domain rules,
privacy requirements, or test suite.
