## Session 2: Free-tier model repair and config schema migration

**Trigger**: Agents kept resolving to `opencode/deepseek-v4.1-flash-free`
regardless of their configured model.

**Diagnosis**

- Configuration *was* loading: `opencode debug config` listed
  `albada/.opencode/opencode.json` (project) and the global files. No root
  `opencode.json` is required; `.opencode/opencode.json` and a root
  `opencode.json` are equivalent, with `.opencode` overriding on conflicts.
- Root cause A: the free IDs `opencode/glm-5.3-flash-free`,
  `opencode/minimax-m3.1-flash-free`, and `opencode/longcat-2.5-preview-free`
  are no longer in the live catalog (only paid `glm-5.3` / `glm-5.3-flash`
  remain), so those agents fell back.
- Root cause B: the `opencode-go` provider is inactive while the Go quota is
  exhausted (zero `opencode-go/*` models), so paid agents fall back. This is
  expected and self-resolves when quota recovers.

**Changes**

| Type | File(s) | Description |
|------|---------|-------------|
| Fix | `agent/principal-free.md` | `glm-5.3-flash-free` -> `opencode/deepseek-v4.1-flash-free`. |
| Fix | `agent/l1-execute-free.md` | `glm-5.3-flash-free` -> `opencode/hy4-flash-free`. |
| Fix | `agent/l1-micro-execute-free.md` | `glm-5.3-flash-free` -> `opencode/beam-free`. |
| Fix | `opencode.json`, `docs/model-routing.md` | Moved `subagent_depth` to `experimental.subagent_depth` and `agent` to `agents`; the top-level forms are deprecated in the V2 schema. |
| Docs | `docs/model-routing.md` | Updated model table, backup order, verification notes, and config-key references. |
| Docs | `docs/model-routing.md`, `docs/skills.md`, `docs/configuration.md` | Corrected stale `.agents/skills` / `skills.paths` references: skills live in `.opencode/skills`, are auto-discovered, and need no `skills` key. |

**Verification**

- `opencode debug agents` resolves `principal-free` -> `opencode/deepseek-v4.1-flash-free`,
  `l1-execute-free` -> `opencode/hy4-flash-free`,
  `l1-micro-execute-free` -> `opencode/beam-free`; all IDs exist in
  `opencode models`.
- `principal` retains its deny-all `permission.task` plus allowlist after the
  `agents` migration.
- Both `opencode.json` files parse as valid JSON.

**Notes**

- Paid agents (`principal`, `l1-execute`, `l2-domain`, `l3-arch`, `fb-kimi`)
  stay on `opencode-go/*` and fall back until the Go quota recovers.
- A root `opencode.json` is kept as an explicit mirror; it is gitignored in the
  Albada repository and lower precedence than `.opencode`.
